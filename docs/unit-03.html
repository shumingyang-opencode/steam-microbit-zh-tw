3.1 兩種主流環境

環境模式適合特點
MakeCode
（Microsoft）		Blocks 方塊低年級/初學者拖拉積木，免記語法
JavaScript中高年級文字程式但保留方塊對照
Python進階方塊轉 Python 程式
MicroPython純文字高年級/進階Python 語法，直接寫程式
建議路徑：方塊（理解邏輯）→ JavaScript/Python 對照（理解語法）→ MicroPython（獨立開發）。同一塊板子可以陪你走完整段旅程。

3.2 MakeCode 介面入門

  • 編輯器：makecode.microbit.org（免安裝，瀏覽器即可）。
  • 模擬器：右側即時模擬，沒板子也能玩。
  • 下載：編譯成 .hex 檔 → 拖進板子即燒錄。
  • 積木分類：基本/輸入/音樂/LED/無線電/邏輯/迴圈/數學。
Hello World
on start ──▶ show string "Hello!"    （開機顯示文字）
on button A pressed ──▶ show icon 😀  （按 A 顯示笑臉）

3.3 燒錄流程（第一次上手）

  1. 用 USB 連接 Micro:bit → 電腦出現 MICROBIT 磁碟。
  2. 在 MakeCode 寫好程式 → 點「下載」。
  3. 把下載的 .hex 檔拖進 MICROBIT 磁碟。
  4. 板子自動重啟並執行；修改時重新下載即可。
常見問題：拖入失敗多半是 USB 線只充電不傳資料（請換「資料線」）；MAC 可能需要確認磁碟權限。

3.4 MicroPython 一瞥

範例
# microbit 官方 MicroPython
from microbit import *

while True:
    display.show(Image.HAPPY)
    if button_a.was_pressed():
        display.scroll("Hi!")
    sleep(100)

MicroPython 用 Mu 編輯器 或 Python Editor（python.microbit.org）寫作，燒錄方式類似。

3.5 Worked Example：第一堂課的兩種開場

範例
【方塊入門（低年級）】
  老師先示範 3 個積木 → 學生照做 → 挑戰改圖案
  下載燒錄 → 完成「我的第一支程式」

【Python 入門（高年級）】
  先展示「hello.py」3 行程式 → 逐行解釋 → 
  挑戰：讓笑臉轉成「眨眼」（交替兩個 Image）

動手：用 MakeCode 完成「按 A 顯示笑臉、按 B 顯示哭臉」，並燒到板子上。

3.6 課堂片段：同一功能，兩種語言

教案片段（25 分鐘）
0-5'   ：先在模擬器執行「按 A 顯示笑臉」
5-10'  ：學生把 Blocks 切換成 JavaScript，圈出相同的事件與動作
10-18' ：教師展示 MicroPython 版本，學生找出 import、if、while
18-23' ：練習：把笑臉改成「按 B 顯示愛心」
23-25' ：出口票：寫一句「我在除錯時先檢查什麼」

除錯檢查表：板子是否連線、事件是否選對、縮排是否一致、等待時間是否造成看不見的輸出。先在模擬器驗證，再下載到實體板，可把問題分成「程式」與「硬體」兩類。

練習：請在 MakeCode 完成「A 顯示 1、B 顯示 2、A+B 顯示 3」，再將其中一個事件改寫成 MicroPython；同伴只看執行結果猜是哪個事件。
看完這單元你應該能說出：
  • 說出 MakeCode 三種模式與適用對象。
  • 說明 MicroPython 與 MakeCode 的差異。
  • 完成一次燒錄流程並執行 Hello World。
