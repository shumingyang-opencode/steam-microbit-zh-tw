9.1 從內建走向外接

內建感測器能「感知」，但要做出真正的工程作品（會動、會叫、會感測環境），需要外接元件。

P0/P1/P2→LED/蜂鳴器/伺服馬達/外接感測器

9.2 基本外接元件

元件接法程式用途
外接 LED腳位 → P0，另一腳 → GNDdigital write P0 (1/0)紅綠燈、指示燈
蜂鳴器腳位 → P0play tone at P0警報、音效
伺服馬達訊號線 → P0servo write P0 角度艙門、轉向
外接感測器訊號 → P0，VCC/GNDanalog read P0超音波、土壤濕度
安全：外接電路請先由老師檢查；確認極性與電阻（LED 串電阻避免過電流）。

9.3 擴充板與模組化

  • 擴充板（Shield）：把 25 個接腳轉成排針或 Grove 介面，插拔方便。
  • Grove / Octopus 模組：標準化的感測器模組（LED、超音波、濕度…），一條線接好。
  • 優點：學生不易接錯、節省時間、專注在「設計」而非「接線」。
工程思維：模組化 = 標準介面 + 可替換元件。讓學生觀察「為什麼擴充板讓工作變快」。

9.4 工程設計流程（EDP）

  1. 問：要解決什麼問題？
  2. 想像：有哪些方案？
  3. 計畫：畫出設計圖。
  4. 建立：組裝與接線。
  5. 測試：跑起來、除錯。
  6. 改進：修正後重測。
與 PBL 的關係：EDP 是 PBL 中「做出作品」那段的核心方法論。

9.5 Worked Example：聲控警報器

範例
問題：安靜的教室裡，有人尖叫怎麼辦？（防霸凌情境）

設計：
  輸入：麥克風（音量）
  判斷：音量 > 150 持續 1 秒
  輸出：LED 閃紅燈 + 蜂鳴器響 + 顯示 "HELP"

程式骨架：
on start: pin P0 = 蜂鳴器
forever:
  if sound level > 150:
    for 5 次: digital write P0 1 → 亮/響 200ms → 0 → 200ms
    show string "HELP"
    pause 5000 ms      ← 冷卻避免重複觸發

測試與改進：誤觸發太多？→ 提高門檻；太安靜？→ 降低。

動手：用外接 LED + 蜂鳴器做一個「光暗警報器」，並走完 EDP 六步驟寫下記錄。

  • 完成一個外接硬體工程專案。
