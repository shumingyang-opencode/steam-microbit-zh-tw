P1.1 什麼是 MicroPython

MicroPython 是為微控制器優化的 Python 3。micro:bit 跑的版本由 MicroPython on micro:bit 提供，常簡稱 microbit 套件。語法幾乎等同一般 Python，你具備的程式基礎可直接套用。

撰寫與執行：micro:bit Python 編輯器（線上），或 MakeCode 的「Python」分頁（可與積木對照）。

MakeCode vs Python 編輯器MakeCode 的 Python 分頁可以直接看到積木對應的 Python 程式碼，適合學習轉換。Python 線上編輯器則提供完整的 MicroPython 環境與序列埠功能。

P1.2 標準匯入

from microbit import *

這行匯入所有常用模組（display、button_a、accelerometer、compass、radio、music…）。相當於 MakeCode 中「自動可用」的所有積木。

P1.4 主迴圈模式

與積木「事件」不同，Python 常用無限迴圈 + 條件做主控流程：

from microbit import *

while True:
    if button_a.was_pressed():
        display.scroll("A")
    sleep(100)
💡 為什麼要 sleep()？micro:bit 是單執行緒，無限迴圈會獨占處理器。加 sleep(100) 給系統喘息空間，避免影響無線電等其他功能，也防止 LED 閃爍過快。

P1.5 Image 與自訂圖案

display.show(Image("90909:09990:09990:00900:00000"))   # 自訂 5x5 愛心
# 9 = 全亮，0 = 滅，1-8 = 漸暗

內建圖案包括 Image.HEART、Image.SMILE、Image.ARROW_N 等，可在官方文件查到完整清單。

P1.6 變數與資料型別

from microbit import *

count = 0              # 整數
name = "micro:bit"     # 字串
pi = 3.14              # 浮點數
is_on = True           # 布林值

while True:
    if button_a.was_pressed():
        count += 1
        display.show(str(count))
    sleep(100)
