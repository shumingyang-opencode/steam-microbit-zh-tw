P2.1 感測器 API 速查

accelerometer.get_x() / get_y() / get_z()   # 三軸力 (mg)
accelerometer.was_gesture("shake")          # 姿勢事件
compass.heading()                            # 方位角 0-360
temperature()                                # 處理器溫度
display.read_light_level()                   # 光度 0-255

P2.2 實作：搖晃計步器

from microbit import *

steps = 0
display.show(str(steps))

while True:
    if accelerometer.was_gesture("shake"):
        steps += 1
        display.show(str(steps))
        sleep(300)          # 防抖動，避免一次搖晃算多步
💡 防抖動（debounce）實務上會短暫延遲避免重複觸發。這是硬體與程式互動的常見考量——感測器在一次搖晃中可能連續觸發多次。

P2.3 實作：羅盤方向儀表板

from microbit import *

compass.calibrate()

def direction(h):
    if h < 45 or h >= 315: return "N"
    if h < 135: return "E"
    if h < 225: return "S"
    return "W"

while True:
    display.show(direction(compass.heading()))
    sleep(300)

P2.4 條件判斷與巢狀

from microbit import *

while True:
    temp = temperature()
    if temp > 30:
        display.show("H")        # Hot
    elif temp < 15:
        display.show("C")        # Cold
    else:
        display.show(Image.SMILE)
    sleep(1000)

P2.5 資料記錄到序列埠

from microbit import *

while True:
    t = temperature()
    l = display.read_light_level()
    print("temp=" + str(t) + " light=" + str(l))
    sleep(2000)

在 Python 編輯器的「序列埠」面板可以看到輸出，方便分析與繪圖。

P2.6 除錯技巧

  • 序列輸出：用 print() 輸出數值觀察，Python 編輯器有 REPL／序列埠
  • 縮排：Python 靠縮排界定區塊，務必用 4 空格（勿用 Tab 混排）
  • 模擬器：Python 編輯器也有模擬器，可即時試跑
  • 錯誤訊息：IndentationError = 縮排問題；NameError = 拼字或忘了 import
