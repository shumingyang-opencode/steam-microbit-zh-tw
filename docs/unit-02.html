2.1 Micro:bit 是什麼

BBC Micro:bit 是英國 BBC 為教育推出的微型電腦（尺寸約 5×4 公分），上面集成了顯示、感測、通訊與輸出入能力。目前主流是 v2（多了麥克風、揚聲器與觸控 Logo）。

輸入→處理（ARM 處理器）→輸出

2.3 內建感測器群（都是科學工具）

感測器量測什麼典型課堂用途
加速度計三軸加速度、傾斜、搖晃水平儀、計步器、搖骰子
磁力計（羅盤）磁場方向方向測量、磁場探測
光感測器環境亮度光線實驗、自動夜燈
溫度感測器晶片/環境溫度溫度監測、保溫實驗
麥克風（v2）音量聲控、音量警報
教學重點：每個感測器背後都有一個「科學原理」可以帶——光=能量、溫度=粒子運動、加速度=力與運動。STEAM 就是從感測器的「讀值」問出「為什麼」。

2.4 接腳與擴充：把世界接進來

  • 接腳 P0/P1/P2：可接外接 LED、蜂鳴器、感測器（見單元 9）。
  • 擴充板（Shield）：把接腳變成好插的排針或 Grove 介面，連接更多元件。
  • 伺服馬達：讓作品「動起來」的輸出元件。
安全提醒：外接電路要由老師確認，避免短路或接錯極性。Micro:bit 本身電壓低，適合教學使用。

2.5 Worked Example：帶學生「讀懂」板子

範例
五分鐘開箱活動（適合第一堂課）：
  1. 找一找：LED 矩陣、按鈕 A/B、Logo、麥克風孔
  2. 猜一猜：這個元件能「輸入」還是「輸出」？
  3. 玩一玩：按下 A → 顯示笑臉（老師預燒範例）
  4. 想一想：生活中有哪些東西也有感測器？
     （手機、自動門、車道閘、溫控空調…）

動手：為你班上的 Micro:bit 開箱課設計 3 個「找一找」線索。

看完這單元你應該能說出：
  • 指認 Micro:bit v2 的各個元件與功能。
  • 說出每個感測器對應的 STEAM 領域。
  • 說出接腳與擴充板的作用。
