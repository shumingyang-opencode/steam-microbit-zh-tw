2.1 Micro:bit 是什麼

BBC Micro:bit 是英國 BBC 為教育推出的微型電腦（尺寸約 5×4 公分），上面集成了顯示、感測、通訊與輸出入能力。目前主流是 v2（多了麥克風、揚聲器與觸控 Logo）。

輸入→處理（ARM 處理器）→輸出

2.3 內建感測器群（都是科學工具）

感測器量測什麼典型課堂用途
加速度計三軸加速度、傾斜、搖晃水平儀、計步器、搖骰子
磁力計（羅盤）磁場方向方向測量、磁場探測
光感測器環境亮度光線實驗、自動夜燈
溫度感測器晶片/環境溫度溫度監測、保溫實驗
麥克風（v2）音量聲控、音量警報
教學重點：每個感測器背後都有一個「科學原理」可以帶——光=能量、溫度=粒子運動、加速度=力與運動。STEAM 就是從感測器的「讀值」問出「為什麼」。

2.4 接腳與擴充：把世界接進來

  • 接腳 P0/P1/P2：可接外接 LED、蜂鳴器、感測器（見單元 9）。
  • 擴充板（Shield）：把接腳變成好插的排針或 Grove 介面，連接更多元件。
  • 伺服馬達：讓作品「動起來」的輸出元件。
安全提醒：外接電路要由老師確認，避免短路或接錯極性。Micro:bit 本身電壓低，適合教學使用。

進階真實情境 Worked Example

以下是一個與上方不同的真實場景，展示多感測器 + 資料視覺化 + 跨裝置通訊的完整工作流。

進階 Worked Example
場景：「多感測器環境數據儀表板」
目標：同時量測光線 + 溫度 + 音量，用 LED 矩陣做「三合一儀表」

工作流：
  1. 設定 forever 迴圈，每 500ms 輪流顯示三種數據
  2. light level → 顯示在第 1 行（高度 0-4 對應 0-255）
  3. temperature → 顯示在第 3 行（高度 0-4 對應 -5~50°C）
  4. sound level → 顯示在第 5 行（高度 0-4 對應 0-255）
  5. 按 A 手動切換「鎖定」某一欄（暫停輪流）

跨裝置通訊進階：
  - 板子 A（感測板）每 2 秒廣播 {light, temp, sound} 的 JSON 封包
  - 板子 B（顯示板）接收後，用 5×5 LED 的「三條水平條」同時呈現
  - 當任一數值超標，顯示板閃爍警示

為什麼選這條路徑？
  → 輪流顯示避免 LED 矩陣塞滿（25 顆 LED 無法同時顯示三種數據）
  → 鎖定功能讓使用者能深入觀察單一指標
  → 分工（感測板 + 顯示板）是 IoT 架構的基礎思維

深入原理擴充

nRF52833 架構深入：Micro:bit v2 的核心 SoC 是 Nordic nRF52833，搭載 ARM Cortex-M4F（含浮點運算單元）。它支援 Bluetooth 5.1、IEEE 802.15.4（Thread/Zigbee），以及 2.4GHz 私有協定——這就是 Micro:bit 無線電的底層技術。

規格數值意義
Flash512 KB儲存程式碼（MakeCode 編譯後約 100-200KB）
RAM128 KB執行時記憶體（變數、堆疊）
ADC 精度10-bit（0–1023）analog read 回傳值範圍，光/溫/音量都經過 ADC 轉換
GPIO25 個接腳 P0-P20 + 3V/GND，可做數位/類比輸出入
陷阱案例：很多人以為 Micro:bit 的溫度感測器是「獨立元件」，其實它是 nRF52833 晶片內建的溫度感測器——量的是晶片溫度，不是環境溫度。當板子長時間運作，晶片自身發熱會讓讀值偏高 2-5°C。解決方案：不要把溫度感測器放在密封盒中、量測前先讓板子「冷卻」30 秒、或使用外接溫度感測器（如 DS18B20）取得更精確的環境溫度。
症狀可能原因解決方案
溫度讀值比實際高 3-5°C晶片自身發熱（正常現象）外接 DS18B20 溫度感測器；或記錄前先暫停板子 30 秒
光線讀值在室內一直跳動LED 矩陣亮滅會影響光感測器讀值讀光線時先 clear screen；或使用外接光敏電阻
analog read 回傳值不穩定類比訊號受接線長度與接觸品質影響使用短接線、確保接線牢固、加裝 0.1μF 去耦電容
觸控 Logo 不靈敏手指潮濕或接觸面積太小用手指腹部按壓；確認 firmware 是最新版
麥克風音量讀值全為 0麥克風被遮蔽或 firmware 未更新確認 Micro:bit v2 的麥克風孔未被膠帶遮住；重新燒錄最新 MakeCode runtime

進階挑戰題

  1. 晶片溫度校正：設計一個實驗，量化 Micro:bit 晶片溫度與實際室溫的差異。在不同條件下（開機 1 分鐘 vs 10 分鐘、LED 全亮 vs 全暗）各量 10 次，畫出「偏差 vs 時間」圖表，並提出一個「校正公式」。
  2. ADC 精度探索：用 analog read 讀取 P0 接腳，把一顆 LED 接在 P0 與 GND 之間。在 LED 串聯不同電阻（100Ω、470Ω、1kΩ、10kΩ）時，各讀 20 次，計算標準差。哪個電阻的讀值最穩定？為什麼？
  3. 硬體逆向工程：查閱 nRF52833 datasheet，找出它的 ADC 採樣率上限是多少？這對 Micro:bit 的感測器專案有什麼限制？（提示：想想「每秒能量測多少次」。）
