15.1 從「主題」到「專案」

一個好的 PBL 要從主題變成可執行專案，需要四個轉換：

步驟內容例子
1. 訂驅動問題開放、可探究「如何減少教室的紙張浪費？」
2. 拆里程碑分階段的目標研究→設計→實作→發表
3. 設計學習單引導探究任務調查表、設計圖、測試紀錄
4. 建立 Rubric評量標準研究/設計/實作/發表 4 維度

15.2 設計學習單

  • 引導而非填空：用開放問題帶思考。
  • 有產出：每張學習單收斂成一個作品片段。
  • 可分組：不同組可做不同版本。
學習單範例
【調查學習單】紙張浪費大調查
1. 預測：我們班一週大概用掉多少張紙？
2. 觀察：記錄今天使用紙張的 5 種情況
3. 分析：哪個用途最浪費？
4. 提議：Micro:bit 能怎麼幫我們少用紙？
   （例如計數器代替紙本點名？）

15.3 里程碑與檢查點

範例
專案：紙張計數器
W1  探索 + 需求定義          → 檢查點：需求清單
W2  設計（畫圖 + 拆模組）    → 檢查點：設計圖
W3  實作（按鈕計數 + 顯示）  → 檢查點：能運作
W4  測試與改進               → 檢查點：測試紀錄
W5  發表                     → 檢查點：作品 + 報告

15.4 建立 Rubric

  • 每個維度 3–4 個等級（如 1–4 分）。
  • 用「可觀察的行為」描述等級。
  • 評分前先給學生看 Rubric（透明度）。
Rubric 範例
維度：實作功能（滿分 4）
  4 完整功能 + 額外特色（如自動重設）
  3 核心功能全運作
  2 部分功能運作
  1 無法運作但有嘗試

維度：團隊合作
  4 分工明確，互相支援，紀錄完整
  3 有分工且大致合作
  2 分工不清，有人沒參與
  1 衝突或各自為政

15.5 Worked Example：一個可複製的 PBL 模板

範例
【PBL 設計模板】主題：________
驅動問題：________________________
真實情境連結：____________________
里程碑：W1____ W2____ W3____ W4____
學習單（3 張）：調查/設計/測試
Rubric 維度：研究□ 設計□ 實作□ 發表□ 合作□
成果發表形式：展示□ 報告□ 互評□

動手：用模板設計一個你自己的 PBL 專案（主題自選）。

看完這單元你應該能說出：
  • 把主題轉成驅動問題與里程碑。
  • 設計學習單引導學生探究。
  • 建立評量 Rubric 的框架。

進階真實情境 Worked Example

以下是一個與上方不同的真實場景，展示多感測器 + 資料視覺化 + 跨裝置通訊的完整工作流。

進階 Worked Example
場景：「跨學科 PBL 評量包」— 環境感測站專案
目標：設計一份同時評量「 STEAM 五個領域」的完整評量系統

評量系統設計：
  Part 1：過程評量（40%）
    - 探究日誌（記錄每堂課的發現與問題）：15%
    - 同伴互評（每週一次 360 度回饋）：10%
    - 教師觀察記錄（技能檢查表）：15%

  Part 2：成果評量（40%）
    - 作品功能（Rubric 4 維度）：20%
    - 數據報告（科學方法完整性）：10%
    - 發表（口頭 + 視覺化）：10%

  Part 3：省思評量（20%）
    - 個人省思文（500 字）：10%
    - 學習歷程 Portfolio：10%

Rubric 範例（作品功能，滿分 4）：
  4：三種感測器正確運作 + 自動校正 + 警報邏輯完善
  3：三種感測器正確運作 + 基本警報
  2：兩種感測器運作 + 部分警報
  1：一種感測器運作或無法運作

設計路徑：
  → 為什麼「過程」佔 40%？
  → 因為 STEAM 的核心是「學習過程」，不是「最終成品」
  → 學生可能做出完美的作品但沒學到東西（抄襲）
  → 也可能作品不完美但學習過程豐富（值得鼓勵）

深入原理擴充

PBL 評量的深層挑戰：傳統評量是「對錯分明」——數學有標準答案、選擇題有唯一解。但 STEAM PBL 的評量需要同時評量「過程」與「成果」，這要求教師發展出全新的評量思維。

評量面向傳統評量PBL 評量
標準唯一正確答案多元標準（Rubric）
時間點單次測驗持續性評量
評分者只有老師老師 + 同伴 + 自我
回饋分數具體描述性回饋
焦點知識記憶能力與態度
陷阱案例：「Rubric 的等級描述太籠統」是最常見的錯誤。例如：「作品很創意」（4 分）vs「作品有基本創意」（3 分）——這兩句話的差別在哪裡？學生看不懂。正確做法是用可觀察的行為：「使用了 3 種以上不同的顯示方式」（4 分）vs「使用了 2 種顯示方式」（3 分）。
症狀可能原因解決方案
學生只關注「做出来」不在乎過程評量只看成果加入過程評量（探究日誌、技能檢查表）
Rubric 每個等級看起來差不多描述太抽象用「數量」或「具體行為」區分等級
同伴互評變成「互相給高分」缺少引導與結構提供互評卡模板（1 讚美 + 1 建議）
Portfolio 收集不完整學生不知道要收集什麼每堂課結束時給「收藏清單」（這堂課的產出）
省思文都寫「我學到很多」省思引導問題太籠統用具體問題：「你改了幾次版本？每次改了什麼？」

進階挑戰題

  1. Rubric 改造：選一個你已經寫好的 Rubric，用「同行審查」的方式請另一位老師（或同伴）審視：每個等級的描述是否「可觀察」？能否從描述中「區分」出不同等級？根據回饋修改。
  2. 同儕互評訓練：設計一個「互評工作坊」：先讓學生練習用 Rubric 評分（用老師提供的範例作品），再讓他們互評。比較「訓練前」與「訓練後」的互評一致性。
  3. 形成性評量設計：為你的 PBL 專案設計 3 個「中途檢查點」（不是最終評量），每個檢查點有明確的「通過標準」和「回饋機制」。討論：形成性評量如何幫助學生在過程中修正方向？
