15.1 從「主題」到「專案」

一個好的 PBL 要從主題變成可執行專案，需要四個轉換：

步驟內容例子
1. 訂驅動問題開放、可探究「如何減少教室的紙張浪費？」
2. 拆里程碑分階段的目標研究→設計→實作→發表
3. 設計學習單引導探究任務調查表、設計圖、測試紀錄
4. 建立 Rubric評量標準研究/設計/實作/發表 4 維度

15.2 設計學習單

  • 引導而非填空：用開放問題帶思考。
  • 有產出：每張學習單收斂成一個作品片段。
  • 可分組：不同組可做不同版本。
學習單範例
【調查學習單】紙張浪費大調查
1. 預測：我們班一週大概用掉多少張紙？
2. 觀察：記錄今天使用紙張的 5 種情況
3. 分析：哪個用途最浪費？
4. 提議：Micro:bit 能怎麼幫我們少用紙？
   （例如計數器代替紙本點名？）

15.3 里程碑與檢查點

範例
專案：紙張計數器
W1  探索 + 需求定義          → 檢查點：需求清單
W2  設計（畫圖 + 拆模組）    → 檢查點：設計圖
W3  實作（按鈕計數 + 顯示）  → 檢查點：能運作
W4  測試與改進               → 檢查點：測試紀錄
W5  發表                     → 檢查點：作品 + 報告

15.4 建立 Rubric

  • 每個維度 3–4 個等級（如 1–4 分）。
  • 用「可觀察的行為」描述等級。
  • 評分前先給學生看 Rubric（透明度）。
Rubric 範例
維度：實作功能（滿分 4）
  4 完整功能 + 額外特色（如自動重設）
  3 核心功能全運作
  2 部分功能運作
  1 無法運作但有嘗試

維度：團隊合作
  4 分工明確，互相支援，紀錄完整
  3 有分工且大致合作
  2 分工不清，有人沒參與
  1 衝突或各自為政

15.5 Worked Example：一個可複製的 PBL 模板

範例
【PBL 設計模板】主題：________
驅動問題：________________________
真實情境連結：____________________
里程碑：W1____ W2____ W3____ W4____
學習單（3 張）：調查/設計/測試
Rubric 維度：研究□ 設計□ 實作□ 發表□ 合作□
成果發表形式：展示□ 報告□ 互評□

動手：用模板設計一個你自己的 PBL 專案（主題自選）。

看完這單元你應該能說出：
  • 把主題轉成驅動問題與里程碑。
  • 設計學習單引導學生探究。
  • 建立評量 Rubric 的框架。
