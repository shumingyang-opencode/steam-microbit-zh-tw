5.1 感測器 = 把世界變成數字

感測器把物理量（光、溫度、運動、音量、磁場）轉成程式可讀的數值。這正是「科學量測」的核心——也是 STEAM 的 S。

物理量→感測器→數值→程式顯示/判斷

5.2 各感測器讀取方式

感測器積木/函式數值範圍單位/意義
光線light level0–2550 暗 → 255 亮
溫度temperature約 -5 – 50°C（晶片溫度）
加速度acceleration x/y/z約 -2048 – 2048mg（重力倍數）
搖動/姿勢on shake / is gesture—事件觸發
羅盤compass heading0–359度（需先校準）
音量（v2）sound level0–255環境音量

5.3 顯示數值的三種方式

  • LED 顯示：show number（數字跑在矩陣上）。
  • 點陣圖：用亮度高度表示大小（如「水銀柱」）。
  • 序列埠：把數據送到電腦做分析（單元 8 詳談）。
範例
on start: serial → 序列埠開啟
forever:
  show number temperature   ← 一直顯示溫度
  pause 1000 ms

5.4 常見課堂實驗

實驗感測器科學問題
手電筒靠近/遠離光亮度與距離的關係
手握板子溫度體溫會不會讓讀值上升？
搖晃板子加速度搖晃強度 vs 加速度值
大聲喊/安靜麥克風音量 vs 讀值變化
教學法連結：讓學生先「預測讀值」再「實測」——這個「預測→驗證」循環就是科學方法。

5.5 Worked Example：光線/溫度「可視化儀表」

範例
專案目標：把光線強度畫成一條 LED「水銀柱」
on start: set brightness 255
forever:
  light = light level           ← 0-255
  level = light / 51            ← 轉成 0-5 格（5 格滿）
  clear screen
  for row in 0..level-1:        ← 從底部往上點亮
    plot x=2, y=4-row
  pause 200 ms

延伸：按 A 切換顯示「光線」，按 B 切換「音量」。

動手：做一個「感測器儀表板」，能切換顯示光線與音量，並畫成水銀柱。

進階真實情境 Worked Example

以下是一個與上方不同的真實場景，展示多感測器 + 資料視覺化 + 跨裝置通訊的完整工作流。

進階 Worked Example
場景：「教室環境全感測儀表板」— 同時監測 4 種環境指標
目標：用一台 Micro:bit 做到「光+溫+音+加速度」四合一量測

工作流：
  1. forever 迴圈中，每 200ms 輪流讀取四種感測器
  2. 用變數 array 存最近 10 筆讀值（滑動視窗）
  3. LED 矩陣顯示目前量測項目的「迷你柱狀圖」（5 格）
  4. 按 A/B 切換顯示項目；長按 A+B 顯示「平均值」

資料視覺化設計：
  - 光線：用「太陽圖案」+ 柱狀圖（越高越亮）
  - 溫度：用「溫度計」動畫（汞柱上升）
  - 音量：用「音波」動畫（點的左右跳動）
  - 加速度：用「水平儀」（點在 5×5 中心偏移）

選這條路徑的原因：
  → 輪流顯示避免資訊 overload（一次只看一個指標）
  → 滑動視窗平均值過濾雜訊（比單次讀值更穩定）
  → 切換功能讓使用者能自主探索不同數據

深入原理擴充

ADC（類比-數位轉換器）精度：Micro:bit 的 analog read 使用 10-bit ADC，回傳值範圍 0–1023。但實際上，這個值是經過 MakeCode runtime 處理後的映射——MakeCode 將 0–1023 映射到 0–255（8-bit），以簡化使用。這意味著 Micro:bit 的光/溫/音量讀值的有效解析度只有 256 級，而非 1024 級。

感測器原始 ADC 範圍MakeCode 映射有效精度
光線0–1023 (10-bit)0–255約 1% 步進
溫度晶片內部感測-5~50°C（約）約 1°C 步進
音量0–1023 (10-bit)0–255約 1% 步進
外接（P0-P2）0–1023 (10-bit)0–1023（完整）約 0.1% 步進
陷阱案例：「light level 讀值不穩定（一直在跳動）」——很多人以為是感測器壞了，其實是因為 Micro:bit 的光感測器就在 LED 矩陣旁邊。LED 亮滅時發出的光會直接干擾光感測器。解決方案：讀光線前先 clear screen（關掉所有 LED）；或在外殼上開一個獨立的「感測窗」，讓光感測器只接收環境光。
症狀可能原因解決方案
光線讀值隨 LED 亮滅跳動LED 光線干擾光感測器讀值前 clear screen；或加裝遮光罩
溫度讀值偏高 3-5°C晶片自身發熱外接 DS18B20；或讀值前暫停板子 30 秒
analog read 為 0 或 1023 不動接線斷路或短路重新接線；確認 VCC/GND/Signal 三線正確
音量讀值全為 0麥克風被遮蔽（v2）確認麥克風孔未被膠帶或手遮住
加速度讀值在靜止時不為 0板子未水平放置（正常）這是重力加速度；需先校準「水平基準」再量測

進階挑戰題

  1. 感測器校準實驗：選一個感測器（光/溫/音），設計校準流程：在已知條件下（如：完全黑暗、已知溫度的水杯旁、安靜房間）量測 20 次，建立「讀值 vs 真實值」的對照表。你的校正公式是什麼？
  2. 多感測器融合：設計一個「跌倒偵測器」，同時使用加速度計（偵測衝擊）+ 麥克風（偵測尖叫聲）。當兩個感測器同時偵測到異常才觸發警報。解釋：為什麼「多感測器融合」比單一感測器更準確？
  3. 數據品質分析：收集光線讀值 100 筆（每秒 1 筆），計算平均值、標準差、最大最小值。用這組數據判斷：你教室的光線穩定嗎？哪個時段波動最大？
