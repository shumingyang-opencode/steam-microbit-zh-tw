12.1 STEAM 的 A：藝術不是裝飾

藝術（A）在 STEAM 裡是創作與表達——讓作品「有感」、有風格、能傳達情緒。音樂、動畫、互動裝置都是藝術。

重點：藝術不是「最後才美化」，而是設計的一部分——好的 STEAM 作品同時是好的藝術品。

12.2 用揚聲器創作音樂（v2）

積木功能
play tone (頻率) for (時間)播放單一音調
start melody播放內建旋律
music beats / tempo控制節奏
範例
小蜜蜂（Do Re Mi…）：
play tone 262 for 400ms   ← C
play tone 294 for 400ms   ← D
play tone 330 for 400ms   ← E
play tone 349 for 400ms   ← F
...
（頻率 = 音階的數學關係！連結 M）
數學連結：音階頻率成等比數列（每 8 度 ×2）——音樂也是數學。

12.3 LED 動畫創作

  • 用「幀」的概念：每幀一張圖案，切換+時間。
  • 用變數記錄「目前是哪一幀」。
  • 結合按鈕：觀眾按鈕觸發不同動畫。
範例
流星動畫：
forever:
  for y in 0..4:
    plot 2, y
    pause 80 ms
    unplot 2, y
（視覺暫留 → 觀眾看到「流星」）

12.4 互動藝術：作品回應觀眾

範例
「觸摸發光音樂盒」
  on logo pressed:        ← 觸控
    播放一段旋律
    forever 閃爍愛心動畫
  on shake:
    停止音樂、換成「雨天」動畫
展覽情境：互動藝術的重點是「觀眾參與」。讓作品擺在校園展示，邀請別人來玩——這是最好的公開成果（PBL 的公開作品）。

12.5 Worked Example：心情音樂盒

範例
作品目標：按不同按鈕，播出不同情緒的音樂+動畫
  A：開心 → 快節奏 + 笑臉動畫
  B：難過 → 慢板 + 哭臉動畫
  Logo：隨機 → 每按一次換一種心情（連結隨機數）

藝術創作引導：
  1. 選一首你熟悉的旋律 → 找出簡譜 → 換成頻率
  2. 為每段配一個 LED 動畫
  3. 發表：解釋你的「創作決定」

動手：創作一個「按 A/B 切換情緒」的音樂動畫作品，並準備 30 秒創作說明。

進階真實情境 Worked Example

以下是一個與上方不同的真實場景，展示多感測器 + 資料視覺化 + 跨裝置通訊的完整工作流。

進階 Worked Example
場景：「互動音樂裝置」— 用加速度計控制音調
目標：像演奏「特雷門琴」一樣，傾斜板子改變音調

技術：
  - 加速度 X 軸 (-1024~1024) 映射到音階頻率 (262~523 Hz)
  - 按 A 切換音階（大調/小調/五聲音階）
  - LED 矩陣顯示目前音階名稱

MicroPython 程式：
  from microbit import *
  import music

  scale_C = [262, 294, 330, 349, 392, 440, 494, 523]
  scale_minor = [262, 294, 311, 349, 392, 415, 466, 523]

  current_scale = scale_C

  while True:
      x = accelerometer.get_x()         ← -1024 to 1024
      index = int((x + 1024) / 256)     ← 映射到 0-7
      index = max(0, min(7, index))
      freq = current_scale[index]
      music.pitch(freq, 100)            ← 播放 100ms

      if button_a.was_pressed():
          current_scale = scale_minor if current_scale == scale_C else scale_C

設計路徑：
  → 為什麼用加速度計而非按鈕？
  → 因為加速度提供「連續控制」（類比），按鈕只有「離散切換」（數位）
  → 連續控制更接近真實樂器的操作方式
  → 連結 STEAM 的 A（音樂創作）+ S（聲學）+ M（頻率映射）

深入原理擴充

音階的數學：音樂中的音階遵循等比數列——每個半音的頻率是前一個的 2^(1/12) ≈ 1.0595 倍。一個八度（12 個半音）正好是頻率 ×2。這就是為什麼「高八度的 Do」頻率是「低八度 Do」的兩倍。

音名頻率 (Hz)與 Do 的比值MakeCode 頻率
Do (C4)2621.000262
Re (D4)2941.122294
Mi (E4)3301.260330
Fa (F4)3491.335349
Sol (G4)3921.498392
La (A4)4401.682440
Si (B4)4941.888494
Do (C5)5232.000523
數學連結：音階的頻率比值可以用「對數」來理解：人耳對音高的感知是對數的（同樣的「距離感」對應倍數而非加法）。這就是為什麼音樂理論和數學這麼密切相關。
症狀可能原因解決方案
音樂播放時 LED 不動play tone 會阻塞執行改用 start melody（非阻塞）；或用 music.pitch 搭配 pause 控制
音調聽起來「走音」頻率值不精確使用精確的頻率值（參考音階表）；避免整數截斷
揚聲器沒聲音v1 沒有內建揚聲器確認使用 Micro:bit v2；或外接蜂鳴器到 P0
音階切換時有雜音頻率突變造成「爆音」在切換前加 music.stop()；或使用频率渐变
LED 動畫與音樂不同步音樂播放阻塞了動畫迴圈將音樂與動畫分開處理（用事件觸發音樂）

進階挑戰題

  1. 音程計算器：在 MakeCode 中實作一個「音程計算器」：按 A 減少半音、按 B 增加半音，LED 顯示目前頻率。從 262Hz（Do）開始，每次加 2^(1/12) 倍。驗證：加 12 次後是否回到 262×2 = 524Hz？
  2. 節奏遊戲：設計一款「節奏遊戲」：LED 顯示「下落的音符」（從頂部落到底部），玩家要在音符到達底部時按下對應按鈕。加入計分系統與難度遞增。
  3. 頻譜分析入門：用 Micro:bit 的麥克風量測環境音量，每 50ms 取樣一次，收集 100 個點。在電腦上畫出「時間 vs 音量」的波形圖。你的教室的「聲音特徵」是什麼？
