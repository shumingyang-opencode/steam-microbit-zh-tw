16.1 一份 STEAM 教案的骨架

一份可執行的 STEAM 教案包含五大區塊：

區塊內容佔課堂比重
教學目標學生學完「能做到什麼」設計起點
活動流程5E 或步驟式活動80%
材料清單Micro:bit/元件/學習單準備
評量方式Rubric/作品/省思收尾
差異化不同程度學生的調整全程

16.2 教學目標怎麼寫

  • 用行為動詞：能「說出/做出/設計/比較/解釋」。
  • 可觀察：目標要是「看得見的表現」。
  • 帶條件與標準：在什麼情境、做到什麼程度。
範例
弱目標：「了解感測器」
強目標：「學生能使用 MakeCode 讀取光感測器數值，
         並在亮度低於 40 時讓 LED 顯示月亮圖案，
         準確率達 9/10 顆 LED 正確。」（可觀察、可評）

16.3 活動流程（結合 5E）

教案活動欄
活動（40 分鐘）
0-5  Engage：關燈情境劇 → 提問
5-15 Explore：玩 light level，記錄 3 種光線
15-25 Explain：討論門檻值 → 示範 if 積木
25-35 Elaborate：實作「月亮燈」+ 音效
35-40 Evaluate：同桌互測 + Rubric

16.4 材料與評量

  • 材料：Micro:bit ×N、USB 線、手電筒、學習單、Rubric 表。
  • 評量：Rubric（實作+合作）+ 學習單 + 課堂觀察。
常見錯誤：教學目標寫了但活動沒對應（目標要「驅動」活動）。每個活動都要能對到一個目標。

16.5 Worked Example：完整教案（月亮燈）

範例
教案：聲控月亮燈
年級：小學中年級 ｜ 時間：40 分鐘
目標：
  1. 能讀取 light level 並描述其範圍（S）
  2. 能用 if 積木依亮度判斷（T）
  3. 能設計「月亮/星星」LED 圖案（A）
材料：Micro:bit、USB 線、手電筒、學習單×2、Rubric
流程：
  0-5  Engage（關燈→提問「怎麼辦」）
  5-15 Explore（3 種光線實測紀錄）
  15-25 Explain（門檻值 + if 積木示範）
  25-35 Elaborate（實作 + 音效 + 圖案）
  35-40 Evaluate（互測 + Rubric + 省思 1 句）
評量：Rubric（功能 4 / 圖案 4 / 合作 3）
差異化：快的組加「自動亮度調整」；慢的組用預設圖案

動手：用教案模板寫一份你自己的 40 分鐘 STEAM 教案。

  • 說出 STEAM 教案的五大區塊。
  • 撰寫清楚的教學目標（行為目標）。
  • 用模板產出一份完整教案。
