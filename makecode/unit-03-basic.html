3.1 Basic 積木總覽

Basic 分類包含最基礎的顯示與控制積木，是所有 MakeCode 程式的起點。

積木參數說明
show numbervalue, duration (ms)在 5×5 LED 上顯示數字，多位數自動滾動
show stringvalue, duration (ms)滾動顯示英文字母或數字
show iconicon (IconNames)顯示 24 種內建圖案（心形、笑臉等）
show ledsleds (LED 圖案)自訂 5×5 LED 亮滅組合
clear screen—清除所有 LED 顯示
forever—重複執行區塊內的積木（無限迴圈）
pausems (number)暫停指定毫秒數（1000ms = 1秒）
on start—程式啟動時執行一次

3.2 顯示數字與文字

show number

show number 42

在 5×5 LED 矩陣上顯示數字。若數字為多位數（如 123），會從右到左滾動顯示。

show string

show string "Hello"

滾動顯示英文字母。每個字母佔用一定的時間，可透過 duration 參數調整速度。

注意：Micro:bit 的 LED 只有 5×5 個像素，所以大寫英文字母和數字是最清晰的選擇。小寫字母如 i、l 可能較難辨識。

3.3 顯示圖案

show icon

show leds（自訂圖案）

點擊 LED 網格可自訂亮滅：

show leds
  . # . # .
  # # # # #
  # # # # #
  # . . . #
  . # # # .

上面的圖案是一個圓圈。在 MakeCode 中，你只需點擊 LED 格子即可切換亮/滅。

3.4 程式執行流程

積木執行方式說明
on start執行一次程式啟動時立即執行，適合初始化變數
forever無限重複執行完區塊後立即重頭開始
重要：若 forever 內沒有 pause，程式會佔用所有處理時間，可能導致按鈕事件無法被偵測。建議在迴圈中加入至少一個 pause。

3.5 範例：呼吸燈效果

forever
  show icon Heart
  pause 500
  clear screen
  pause 500

JavaScript 對應程式碼：

forever(() => {
  basic.showIcon(IconNames.Heart)
  basic.pause(500)
  basic.clearScreen()
  basic.pause(500)
})

3.6 範例：倒數計時器

on start
  show number 3
  pause 1000
  show number 2
  pause 1000
  show number 1
  pause 1000
  show icon Yes
🔗 在 MakeCode 中開啟倒數計時器範例
