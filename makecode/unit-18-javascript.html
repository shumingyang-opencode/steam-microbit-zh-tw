18.1 為什麼要學 JavaScript

MakeCode 使用 Static TypeScript（JavaScript 的超集）作為文字模式的語言。從積木轉到 JavaScript 可以：

好處說明
更靈活某些功能只有文字模式才能實現
更簡潔複雜邏輯用文字表達更清楚
更容易大量程式碼可以快速複製貼上
學習橋樑銜接到真正的 JavaScript/TypeScript 開發

積木→JavaScript

18.2 切換到 JavaScript 模式

  1. 在 MakeCode 編輯器上方，找到「JavaScript」按鈕
  2. 點擊切換到 JavaScript 模式
  3. 你會看到目前的積木程式自動轉換為 JavaScript 程式碼
  4. 可以直接在文字編輯器中修改程式碼
重點：MakeCode 支援雙向即時轉換——在積木模式下修改會立即反映在 JavaScript 中，反之亦然。但某些 JavaScript 寫法可能無法轉回積木。

18.4 JavaScript 進階語法

陣列操作

// 陣列的 JavaScript 寫法
let colors = ["red", "green", "blue"]

// 迴圈遍歷
for (let color of colors) {
    basic.showString(color)
}

// 陣列方法
colors.push("yellow")
colors.pop()
let index = colors.indexOf("green")

物件

// 簡單物件
let player = {
    name: "Player1",
    score: 0,
    level: 1
}

basic.showString(player.name)
player.score += 10

箭頭函式

// 傳統寫法
input.onButtonPressed(Button.A, function () {
    basic.showIcon(IconNames.Heart)
})

// 箭頭函式（更簡潔）
input.onButtonPressed(Button.A, () => {
    basic.showIcon(IconNames.Heart)
})

18.5 常見 JavaScript 模式

狀態機

// 使用物件管理遊戲狀態
let game = {
    state: "menu",
    score: 0,
    lives: 3
}

input.onButtonPressed(Button.A, function () {
    if (game.state === "menu") {
        game.state = "playing"
        basic.showString("GO!")
    } else if (game.state === "playing") {
        game.score += 10
        basic.showNumber(game.score)
    }
})

計時器

// 簡易計時器
let startTime = 0
let elapsed = 0

input.onButtonPressed(Button.A, function () {
    startTime = input.runningTime()
    basic.showString("START")
})

input.onButtonPressed(Button.B, function () {
    elapsed = input.runningTime() - startTime
    basic.showString("" + elapsed + "ms")
})

18.6 實作練習：積木轉 JavaScript

  1. 在積木模式下建立一個計分遊戲
  2. 切換到 JavaScript 模式觀察轉換結果
  3. 在 JavaScript 模式下修改程式碼
  4. 切換回積木模式，看看哪些修改可以轉回積木
