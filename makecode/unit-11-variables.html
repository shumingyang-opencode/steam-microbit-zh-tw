11.1 什麼是變數

變數就像一個「容器」，用來儲存程式執行過程中的資料。你可以把變數想像成一個貼了標籤的盒子，標籤是變數名稱，盒子裡裝的東西就是變數的值。

概念說明範例
變數名稱用來識別變數的標籤score、level、userName
變數值變數中儲存的資料0、"hello"、true
變數類型資料的型別數字、字串、布林值

11.2 建立與使用變數

在 MakeCode 中，使用變數分類中的積木來管理變數：

建立變數

  1. 點擊變數分類
  2. 點擊「建立一個變數…」
  3. 輸入變數名稱（例如：score）
  4. 點擊「確定」

變數積木一覽

積木說明積木/JavaScript
設定 [變數] 為 [0]建立或重設變數let score = 0
將 [變數] 改變 [1]在原值上加減score += 1
[變數]讀取變數的值score
重點：「設定」是把值放進盒子，「改變」是在原值上加減。例如先設定 score 為 0，再改變 10，score 就變成 10。

程式範例：計分遊戲

// 顯示隨機數字，按下 A 後判斷
let answer = 0
let guess = 0
answer = randint(1, 9)
basic.showString("" + answer)
input.onButtonPressed(Button.A, function () {
    guess = randint(1, 9)
    basic.showString("" + guess)
    if (guess === answer) {
        basic.showIcon(IconNames.Yes)
    } else {
        basic.showIcon(IconNames.No)
    }
})

11.5 實作練習：成績計算器

  1. 建立變數 total（總分）和 count（計數）
  2. 每按下 A，將隨機分數加入 total，count 加 1
  3. 按下 B，顯示平均分數（total ÷ count）
  4. 同時按下 A+B，重設所有變數
let total = 0
let count = 0
let avg = 0
input.onButtonPressed(Button.A, function () {
    let grade = randint(60, 100)
    total += grade
    count += 1
    basic.showString("A")
})
input.onButtonPressed(Button.B, function () {
    avg = total / count
    basic.showNumber(avg)
})
input.onButtonPressed(Button.AB, function () {
    total = 0
    count = 0
    basic.clearScreen()
})
