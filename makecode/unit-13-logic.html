13.1 條件判斷的概念

條件判斷讓程式根據不同情況執行不同的程式碼。就像日常生活中的「如果...就...否則...」邏輯：

  • 如果下雨 → 帶傘
  • 如果沒下雨 → 不帶傘
  • 如果溫度超過 35 度 → 開冷氣

13.2 if 判斷

最基本的條件判斷：如果...那麼

積木說明JavaScript
如果 <條件> 那麼條件為 true 時執行if (condition) { ... }
// 按 A 顯示愛心
input.onButtonPressed(Button.A, function () {
    basic.showIcon(IconNames.Heart)
})

// 如果按住 A+B，顯示笑臉
input.onButtonPressed(Button.AB, function () {
    basic.showIcon(IconNames.Happy)
})

13.3 if/else 判斷

增加否則分支，處理條件不成立的情況：

積木說明JavaScript
如果 <條件> 那麼 ... 否則二選一執行if (cond) { ... } else { ... }
// 偶數顯示 O，奇數顯示 X
input.onButtonPressed(Button.A, function () {
    let num = randint(1, 100)
    basic.showNumber(num)
    basic.pause(1000)
    if (num % 2 === 0) {
        basic.showString("E")  // Even 偶數
    } else {
        basic.showString("O")  // Odd 奇數
    }
})

13.4 巢狀判斷

在一個 if 裡面再放另一個 if，形成多層判斷：

// 成績評等
input.onButtonPressed(Button.A, function () {
    let score = randint(0, 100)
    basic.showNumber(score)
    basic.pause(2000)
    if (score >= 90) {
        basic.showString("A")
    } else {
        if (score >= 80) {
            basic.showString("B")
        } else {
            if (score >= 60) {
                basic.showString("C")
            } else {
                basic.showString("F")
            }
        }
    }
})
重點：巢狀判斷不要嵌套太深（建議不超過 3 層），否則程式會難以閱讀和維護。

13.5 邏輯運算

使用邏輯運算符組合多個條件：

運算積木JavaScript說明
且（AND）<條件A> 且 <條件B>&&兩者都為 true 才是 true
或（OR）<條件A> 或 <條件B>||任一為 true 就是 true
非（NOT）非 <條件>!true 變 false，false 變 true
// 同時按下 A+B 時顯示星星
input.onButtonPressed(Button.AB, function () {
    basic.showIcon(IconNames.Star)
})

// 按 A 或 B 都顯示箭頭
input.onButtonPressed(Button.A, function () {
    basic.showArrow(ArrowNames.West)
})
input.onButtonPressed(Button.B, function () {
    basic.showArrow(ArrowNames.East)
})

13.6 實作練習：智慧溫度計

  1. 使用溫度感測器讀取目前溫度
  2. 根據溫度顯示不同圖示：
    • 低於 20°C：顯示雪花 ❄️
    • 20~30°C：顯示笑臉 😊
    • 超過 30°C：顯示火焰 🔥
  3. 使用巢狀判斷完成三種溫度範圍
basic.forever(function () {
    let temp = input.temperature()
    if (temp < 20) {
        basic.showString("C")
    } else {
        if (temp <= 30) {
            basic.showIcon(IconNames.Happy)
        } else {
            basic.showString("H")
        }
    }
})
