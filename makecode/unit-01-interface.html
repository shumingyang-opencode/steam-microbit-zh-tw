1.1 MakeCode 是什麼

Microsoft MakeCode 是一個免費的線上程式編輯器，專為 Micro:bit 設計。它支援三種程式模式：

模式說明適合對象
積木（Blocks）視覺化拖曳積木，類似 Scratch初學者、小學生
JavaScript文字程式碼，使用 Static TypeScript有程式基礎者
Python文字程式碼，使用 MakeCode Python想學 Python 者
重點：MakeCode 支援雙向轉換——在積木模式下撰寫，可以即時看到對應的 JavaScript/Python 程式碼；反之亦然。

開啟 makecode.microbit.org，你會看到以下介面：

工作區（中間）撰寫程式的區域，將積木拖曳到這裡組合
模擬器（左側）即時模擬 Micro:bit 執行結果

1.3 專案管理

建立新專案

  1. 開啟 makecode.microbit.org
  2. 點擊「新專案」
  3. 輸入專案名稱（例如：「我的第一個專案」）
  4. 選擇「積木」模式

儲存與載入

  • 自動儲存：MakeCode 會自動儲存到瀏覽器本機
  • 匯出檔案：點擊「…」→「下載專案」儲存為 .mkcd 檔案
  • 匯入檔案：點擊「Import」→ 選擇 .mkcd 檔案

1.4 下載與燒錄

編輯完程式後，需要將程式下載並燒錄到 Micro:bit 板子上才能實際運行。以下是完整步驟：

步驟 1：點擊下載按鈕

MakeCode 編輯器右下角的紫色「下載」按鈕（紅色框標示處）

  1. 在 MakeCode 編輯器中完成程式編輯
  2. 點擊右下角紫色的「下載」按鈕
  3. 瀏覽器會自動下載一個 .hex 檔案

步驟 2：連接 Micro:bit

用 USB 線將 Micro:bit 連接到電腦

  1. 準備一條 Micro USB 線（與手機充電線相同）
  2. 將 Micro USB 端插入 Micro:bit 的 USB 接口
  3. 將標準 USB 端插入電腦的 USB 接口

步驟 3：燒錄程式

Micro:bit v2 板子外觀（正面）

  1. 連接後，電腦會自動出現一個名為 MICROBIT 的可卸除式磁碟
  2. 將下載的 .hex 檔案拖曳到 MICROBIT 磁碟中
  3. 等待 Micro:bit 背面的 LED 閃爍，表示燒錄中
  4. LED 停止閃爍後，燒錄完成！程式會自動開始運行

MakeCode 官方說明：如何將程式傳輸到 Micro:bit

注意：燒錄過程中請勿拔除 USB 線，否則可能導致韌體損壞。如果 Micro:bit 無法正常工作，可以嘗試重新燒錄。
小提示：你也可以使用 MakeCode 的「下載」按鈕直接透過 WebUSB 連接 Micro:bit（需使用 Chrome 瀏覽器），這樣就不需要手動拖曳檔案。

1.5 模擬器使用

MakeCode 內建模擬器，可以在不連接硬體的情況下測試程式：

功能操作
自動執行積木改動後，模擬器會自動重新執行
暫停/繼續點擊模擬器上方的暫停按鈕
重啟點擊模擬器上方的重啟按鈕
虛擬按鈕點擊模擬器上的 A/B 按鈕測試
虛擬晃動點擊模擬器旁的晃動圖示
