Python 是全球最受歡迎的程式語言之一，MakeCode 支援直接在 Micro:bit 上使用 Python：

積木→Python

19.2 切換到 Python 模式

  1. 在 MakeCode 編輯器上方，找到「Python」按鈕
  2. 點擊切換到 Python 模式
  3. 積木程式會自動轉換為 Python 程式碼
  4. 可以直接在文字編輯器中修改
重點：MakeCode Python 是 Micro:bit Python 的子集。部分 Python 標準庫功能可能不支援，但所有 MakeCode 積木功能都能對應。

19.4 Python 範例程式

倒數計時器

# 倒數計時器
for i in range(10, 0, -1):
    basic.show_number(i)
    basic.pause(1000)
basic.show_string("GO!")

溫度顯示器

# 即時顯示溫度
while True:
    temp = input.temperature()
    if temp > 30:
        basic.show_string("HOT")
    elif temp < 10:
        basic.show_string("COLD")
    else:
        basic.show_icon(IconNames.HAPPY)
    basic.pause(2000)

計分遊戲

# 簡單計分遊戲
score = 0
target = randint(1, 9)

def check_answer(guess):
    global score, target
    if guess == target:
        score += 10
        basic.show_icon(IconNames.YES)
    else:
        basic.show_icon(IconNames.NO)
    basic.pause(500)

def on_button_a():
    check_answer(randint(1, 9))

input.on_button_pressed(Button.A, on_button_a)

def on_button_b():
    basic.show_number(score)

input.on_button_pressed(Button.B, on_button_b)

basic.show_string("A=Play B=Score")

19.5 Python 進階功能

列表操作

# 陣列（列表）操作
fruits = ["apple", "banana", "cherry"]

# 迴圈遍歷
for fruit in fruits:
    basic.show_string(fruit)

# 加入元素
fruits.append("date")

# 搜尋
if "banana" in fruits:
    basic.show_string("Found!")

字典

# 使用字典管理資料
scores = {
    "Alice": 95,
    "Bob": 87,
    "Charlie": 92
}

basic.show_string(scores["Alice"])

19.6 MakeCode Python vs 純 Python

特性MakeCode Python純 Python
執行環境MakeCode 編輯器 / Micro:bit電腦 / 伺服器
標準庫僅 MakeCode API完整標準庫
套件管理不支援 pip支援 pip
檔案操作不支援完整支援
網路功能僅 Bluetooth/Radio完整 HTTP/TCP
注意：MakeCode Python 程式碼不完全等於標準 Python。例如 basic.show_icon() 是 MakeCode 專有 API，無法在一般 Python 環境中執行。
