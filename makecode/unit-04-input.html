4.1 Input 積木總覽

Input 分類處理來自 Micro:bit 硬體的各種輸入訊號，包括按鈕、感測器和無線電。

積木類型回傳值說明
on button pressed事件—按鈕 A/B/任意 被按下時觸發
on shake事件—晃動 Micro:bit 時觸發
button A is pressed布林true/false檢查按鈕是否被按住
temperature (°C)數值0~50讀取溫度感測器 (°C)
light level數值0~255讀取光線感測器強度
acceleration (mg)數值-2048~2047讀取加速度（各軸或總量）
rotation (pitch/roll)數值-180~180讀取旋轉角度
compass heading數值0~359讀取指南針方向 (度)
sound level數值0~255讀取環境音量
pin A0 pressed布林true/false檢查外部按鈕是否被按下

4.2 按鈕事件

事件型：on button pressed

on button A pressed
  show icon Happy

當按下按鈕 A 時，顯示笑臉。這是事件驅動的寫法——程式會在背景等待事件發生。

狀態型：button A is pressed

forever
  if button A is pressed then
    show icon Heart
  else
    clear screen

持續檢查按鈕 A 是否被按住（注意：是按住，不是點擊）。

比較on button pressedbutton A is pressed
觸發方式按下瞬間觸發一次按住期間持續回傳 true
使用場景按一下執行某個動作按住期間持續某個行為
放在哪裡頂部，不需放在 forever 內需放在 if 或 forever 內

4.3 晃動偵測

on shake
  show icon Diamond
  music ring

可偵測的晃動類型：

晃動類型說明
shake一般晃動
logo upMicro:bit 的 Logo 朝上
logo downMicro:bit 的 Logo 朝下
screen upLED 面朝上
screen downLED 面朝下
tilt left向左傾斜
tilt right向右傾斜
freefall自由落體
3G、6G、8G承受特定 G 力

4.4 環境感測器

溫度感測器

forever
  show number temperature (°C)
  pause 2000

Micro:bit 內建溫度感測器，可讀取 0~50°C 的環境溫度。測量精度約 ±2°C。

光線感測器

forever
  if light level > 128 then
    show icon Sun
  else
    show icon Moon

利用 LED 反向作為光線感測器，數值範圍 0（暗）~ 255（亮）。

聲音感測器

forever
  show bar graph of sound level
  pause 100

利用內建麥克風測量環境音量（Micro:bit V2 支援）。

4.5 動作感測器

加速度計

參數說明範例值
x左右方向加速度左右晃動時變化
y前後方向加速度前後傾斜時變化
z上下方向加速度拿起/放下時變化
strength三軸合力靜止時約 1023 mg
forever
  show number acceleration strength
  pause 100

陀螺儀（旋轉感測）

參數說明
pitch前後傾斜角度（-180°~180°）
roll左右傾斜角度（-180°~180°）

4.6 範例：計步器

let steps = 0
on start
  steps = 0

on shake
  steps = steps + 1
  show number steps

JavaScript 對應程式碼：

let steps = 0
steps = 0

input.onGesture(Gesture.Shake, () => {
  steps += 1
  basic.showNumber(steps)
})
