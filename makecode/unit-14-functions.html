14.1 為什麼需要函式

函式（Function）是一段可以重複使用的程式碼區塊。當你發現自己在不同地方寫了相同的程式碼，就該把它提取成函式。

好處說明
重複使用同一段程式碼可以在不同地方呼叫
可讀性用有意義的函式名稱取代一大段程式碼
易於維護修改一次函式，所有呼叫處都會更新
除錯方便可以單獨測試每個函式

自訂函式

14.2 建立無參數函式

在 MakeCode 中，使用函式分類建立自訂函式：

  1. 點擊函式分類
  2. 點擊「建立一個函式…」
  3. 輸入函式名稱（例如：showHeart）
  4. 點擊「確定」
// 自訂函式：顯示愛心
function showHeart() {
    basic.showIcon(IconNames.Heart)
    basic.pause(500)
    basic.clearScreen()
}

// 呼叫函式
showHeart()
showHeart()

14.3 帶參數的函式

參數讓函式可以接受不同的輸入值，增加靈活性：

函式定義說明JavaScript
function flash(count)一個數字參數function flash(count: number) { ... }
function greet(name)一個字串參數function greet(name: string) { ... }
// 自訂函式：閃爍 N 次
function flash(count: number) {
    for (let i = 0; i < count; i++) {
        basic.showIcon(IconNames.Yes)
        basic.pause(200)
        basic.clearScreen()
        basic.pause(200)
    }
}

// 呼叫函式，傳入不同參數
flash(3)
flash(5)

14.4 有回傳值的函式

函式可以用 回傳 把結果傳回來：

// 自訂函式：計算兩數相加
function add(a: number, b: number) {
    return a + b
}

// 使用回傳值
let result = add(3, 5)
basic.showNumber(result)  // 顯示 8

進階範例：溫度等級判斷

// 回傳溫度等級字串
function tempLevel(t: number) {
    if (t < 20) {
        return "COLD"
    } else if (t <= 30) {
        return "OK"
    } else {
        return "HOT"
    }
}

basic.forever(function () {
    let level = tempLevel(input.temperature())
    basic.showString(level)
})

14.5 函式模組化實戰

將程式拆分成多個函式，讓結構更清晰：

// 遊戲函式模組
function initGame() {
    score = 0
    lives = 3
    basic.showString("GO!")
}

function loseLife() {
    lives -= 1
    basic.showIcon(IconNames.No)
    basic.pause(500)
    if (lives <= 0) {
        gameOver()
    }
}

function gameOver() {
    basic.showString("GAME OVER")
    basic.showNumber(score)
}

let score = 0
let lives = 3

input.onButtonPressed(Button.A, function () {
    score += 10
    basic.showNumber(score)
})

input.onButtonPressed(Button.B, function () {
    loseLife()
})

initGame()
重點：好的函式名稱應該清楚描述它做什麼。例如 showHeart 比 func1 好得多。

  1. 建立函式 showEmoji(type)，根據參數顯示不同表情

  3. 建立函式 scrollMessage(msg)，滾動顯示訊息
