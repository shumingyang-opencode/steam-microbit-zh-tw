17.1 模擬器基本操作回顧

在單元 1 中我們已經認識了模擬器的基本功能。這個單元我們要深入探討進階用法：

功能操作方式說明
自動執行積木改動後自動重跑即時看到結果
暫停/繼續點擊暫停按鈕觀察程式狀態
重啟點擊重啟按鈕從頭執行
按鈕互動點擊模擬器上的 A/B 按鈕測試按鈕事件

17.2 虛擬感測器

模擬器提供多種虛擬感測器，即使沒有實體硬體也能測試：

感測器模擬方式對應積木
溫度拖曳溫度計input.temperature()
光線拖曳光線計input.lightLevel()
聲音調整音量滑桿input.soundLevel()
磁力拖曳磁力計input.magneticField()
加速度點擊晃動按鈕input.acceleration()
指南針拖曳指南針input.compassHeading()
// 模擬溫度警報
basic.forever(function () {
    let temp = input.temperature()
    if (temp > 30) {
        basic.showString("HOT!")
        music.playTone(262, 200)
    } else if (temp < 10) {
        basic.showString("COLD!")
        music.playTone(523, 200)
    } else {
        basic.showIcon(IconNames.Happy)
    }
    basic.pause(1000)
})

17.3 使用 Console 除錯

MakeCode 的 Console（控制台）是重要的除錯工具：

  1. 點擊模擬器下方的「Show Console」按鈕
  2. 在程式中使用 console.log() 輸出資訊
  3. 在 Console 中觀察變數值和執行流程
// 使用 Console 追蹤變數
let counter = 0
basic.forever(function () {
    counter += 1
    console.log("Counter: " + counter)
    if (counter > 10) {
        console.log("Reset!")
        counter = 0
    }
    basic.pause(500)
})
重點：Console 除了文字輸出，還支援圖表顯示。使用 console.plot() 可以即時繪製數值變化圖。

17.4 模擬器上的图表

使用 console.plot() 即時繪製感測器數據：

// 即時繪製溫度變化圖
basic.forever(function () {
    let temp = input.temperature()
    console.plot(temp)
    basic.pause(1000)
})

17.5 模擬器限制與注意事項

功能模擬器支援說明
LED 顯示✅ 完整支援5×5 矩陣完整模擬
按鈕事件✅ 完整支援A、B、A+B 按鈕
感測器⚠️ 部分支援可模擬，但值為虛擬
音樂⚠️ 部分支援瀏覽器音效
Radio❌ 不支援需要實體硬體
Bluetooth❌ 不支援需要實體硬體
GPIO 腳位❌ 不支援需要實體硬體
注意：模擬器無法完全取代實體硬體。建議先用模擬器測試邏輯，再燒錄到實體 Micro:bit 測試完整功能。

17.6 實作練習：感測器數據記錄器

  1. 使用模擬器的溫度和光線感測器
  2. 每秒讀取一次數據
  3. 使用 Console.plot() 繪製即時圖表
  4. 按下 A 暫停記錄，按 B 繼續
let logging = true

input.onButtonPressed(Button.A, function () {
    logging = false
    basic.showString("PAUSE")
})
input.onButtonPressed(Button.B, function () {
    logging = true
    basic.showString("GO")
})

basic.forever(function () {
    if (logging) {
        let temp = input.temperature()
        let light = input.lightLevel()
        console.log("T:" + temp + " L:" + light)
        console.plot(temp, light)
    }
    basic.pause(1000)
})
