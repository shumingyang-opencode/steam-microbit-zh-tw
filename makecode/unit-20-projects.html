20.3 專案實戰：完整猜數字遊戲

我們以「猜數字遊戲」為例，完整走一遍開發流程：

功能規劃

  • 電腦隨機產生 1~100 的數字
  • 玩家按 A 加一、按 B 減一來調整猜測值
  • 同時按 A+B 確認猜測
  • 提示「大了」或「小了」
  • 猜對後顯示次數並重開新局

完整程式碼

// 猜數字遊戲
let answer = 0
let guess = 0
let attempts = 0
let gameOver = false

function newGame() {
    answer = randint(1, 100)
    guess = 50
    attempts = 0
    gameOver = false
    basic.showString("?")
}

function checkGuess() {
    attempts += 1
    if (guess === answer) {
        basic.showIcon(IconNames.Yes)
        basic.showString("" + attempts + "x")
        gameOver = true
    } else if (guess < answer) {
        basic.showArrow(ArrowNames.North)
        basic.showNumber(guess)
    } else {
        basic.showArrow(ArrowNames.South)
        basic.showNumber(guess)
    }
}

// 按 A：猜測值 +10
input.onButtonPressed(Button.A, function () {
    if (!gameOver) {
        guess += 10
        if (guess > 100) guess = 100
        basic.showNumber(guess)
    }
})

// 按 B：猜測值 -10
input.onButtonPressed(Button.B, function () {
    if (!gameOver) {
        guess -= 10
        if (guess < 1) guess = 1
        basic.showNumber(guess)
    }
})

// 按 A+B：確認猜測
input.onButtonPressed(Button.AB, function () {
    if (!gameOver) {
        checkGuess()
    } else {
        newGame()
    }
})

// 晃動：開始新遊戲
input.onGesture(Gesture.Shake, function () {
    newGame()
})

// 開始遊戲
newGame()

20.4 除錯技巧

技巧方法適用情況
Console 除錯console.log()追蹤變數值變化
